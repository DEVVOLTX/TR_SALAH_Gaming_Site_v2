# Trusted Salah — Gaming Top-up Store

A responsive Arabic RTL gaming top-up storefront built with React, Vite, and Tailwind CSS 4. The visual system is based on the Apple Dark Design System supplied in the brief.

## Run locally

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Included
- Responsive Arabic RTL landing page
- Dark Apple-inspired visual system: Obsidian, Graphite, Carbon, Porcelain, restrained Apple Blue
- Game catalogue with category filters and search
- Purchase details modal with Player ID and package selection
- Interactive demo cart with remove action
- Mobile navigation and empty search state
- Keyboard focus states and reduced-motion support

## Important
This is a front-end prototype. Game prices are illustrative, and checkout/payment/top-up APIs are not connected. Replace `support@example.com` with the real support contact. Product photography is loaded from Unsplash URLs, so those images require internet access.
